# Support

Chronicle is in a design and pre-alpha stage. There is no production support commitment for the open-source project yet.

## Where to ask

- Use a GitHub issue for a reproducible bug, a bounded feature request, or a documentation problem.
- Use an RFC for changes to public contracts, trust boundaries, persistence semantics, governance, or architecture.
- Use the repository's private vulnerability-reporting channel for security concerns.

Before opening an issue, search the existing issues, roadmap, specifications, ADRs, and RFCs.

## What maintainers can provide

Maintainers will make a reasonable effort to triage complete reports. Response times are not guaranteed. The issue tracker is not an emergency channel, a private support desk, or a substitute for deployment-specific professional advice.

Commercial implementation, migration, training, managed hosting, and support may be offered separately by Arios Technologies. Those services do not change the rights or capabilities of the open-source project.
